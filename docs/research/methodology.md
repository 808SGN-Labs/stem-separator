# Methodology

Status: TODO — to be frozen before large benchmark runs.

## Principles
- Same input material across compared configurations.
- Exact checkpoint identity and hashes.
- Fixed reference machine for v1.
- Warm-up/loading effects documented separately where relevant.
- Repeated measurements where timing variability matters.
- Ground-truth metrics only where valid reference stems exist.
- Subjective observations clearly separated from objective measurements.
- No universal "best" claims from one genre, source, or machine.

## Experimental funnel
1. short-excerpt screening
2. controlled benchmark
3. full-track validation
