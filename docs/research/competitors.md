## Conclusions

The following are not defensible standalone USPs:
- local separation
- offline separation
- CPU support
- multi-model access
- open-source separation
- model comparison
- a large model catalog

Potential StemLab differentiation is the combination of:
- CPU-constrained evaluation
- reproducible evidence
- quality-versus-compute analysis
- task-oriented model recommendations
- multi-stage recipe research
- large unattended local queues
- offline operation
- producer-oriented execution of benchmark knowledge

Working positioning:

> StemLab doesn't just give CPU users models. It measures which ones are worth waiting for.
